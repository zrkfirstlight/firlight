## 从一页笔记开始

写作可以从一个具体问题开始。把问题记下来，再为它寻找例子与解释，零散的笔记便逐渐拥有线索。中文排版需要适当的行距与段落间隔，让长句子也能平静地读下去。

这套博客把公开内容与交流功能分开：文章存放在 Markdown 文件中，图片与文章一起保存。即使提供评论的电脑离线，文字、目录、分类与站内搜索也能继续使用。

### 观察与整理

在整理过程中，可以先写事实，再补充自己的理解。这里的文字是排版示例，不应当作为个人简介或项目履历使用。真正发布之前，请替换所有占位内容。

图片为本项目原创 SVG 插图，无需依赖远程图库。标题、说明和正文各自承担不同的阅读作用。

## 一个简短的代码例子

```python
from pathlib import Path

def read_notes(folder: Path):
    for note in sorted(folder.glob("*.md")):
        yield note.read_text(encoding="utf-8")

print("你好，Markdown")
```

代码块使用主题原生高亮。较长的代码行在自己的区域内横向滚动，不会撑开整个页面。

## 用公式表达关系

行内公式：\(a^2+b^2=c^2\)。独立公式：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## 信息的层次

| 元素 | 用途 |

| 标签 | 标记文章涉及的具体关键词 |

3. 在结尾留下进一步探索的问题。

## 延伸记录

当一篇文章变长，可以把背景、过程与结论拆成不同小节。目录帮助读者快速返回某一段，搜索则帮助读者重新找到它。手机上也应保持同样清晰的次序。

写完之后，再通读一遍：链接是否有效，图片是否具有替代文字，代码与公式是否准确。删除不必要的装饰，保留能帮助理解的内容。这里的段落用于形成足够长的阅读页面，方便实际检查滚动、目录与评论区域的关系。
